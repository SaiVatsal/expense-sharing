# Project 26: Expense Sharing App (SplitMint)

A bill-splitting and multi-party debt simplification application built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Friendly Mint Green Palette**: Clean, modern aesthetics (`#f0fdf4`, `#22c55e`, `#15803d`) with rounded Quicksand typography and avatar-forward member cards.
- **Group Circle Management**: Organize shared expenses across travel trips, roommates, dinner outings, and event teams.
- **Flexible Split Algorithms**: Equal splits, percentage allocations, and custom amounts.
- **Debt Graph Simplification**: Minimum-transaction graph solver calculating the exact pairwise debt settlements.
- **One-Click Settle Up**: Clear running debts and track payment status.
- **Running Ledger**: Complete chronological record of itemized receipts by category.

## Getting Started
```bash
npm install
npm run dev
```
